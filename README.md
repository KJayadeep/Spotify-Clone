## 🧾 About The Project  
Built as a clone of the popular music streaming service, this project is a modern web application that replicates key features of user-friendly streaming platforms. It is designed to be fully responsive and includes playback controls, smooth UI/UX, and a clean architecture.

---

## ✅ Features  
- Responsive design for desktop, tablet & mobile  
- Browse & play tracks (simulated playback)  
- Search functionality for songs / artists  
- Playlist creation & editing  
- Dark / Light mode  
- Intuitive navigation and UI visual polish  
- Built with performance and accessibility in mind
